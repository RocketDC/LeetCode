# Java Interview Questions Practice

This project is designed to help you practice Java programming interview questions. Each question is implemented as a separate class in the `src/main/java` directory.

## Project Structure

- `src/main/java` - Contains the implementation of interview questions
- `src/test/java` - Contains JUnit test cases for each question

## Getting Started

1. Clone this repository
2. Ensure you have Java JDK installed (version 8 or higher recommended)
3. Install Maven if not already installed
4. Run `mvn clean install` to build the project

## Adding New Questions

1. Create a new Java class in the appropriate package under `src/main/java`
2. Add JUnit test cases in `src/test/java`
3. Run `mvn test` to verify your solution

## Contributing

Feel free to add new interview questions and solutions. Please follow these guidelines:
- Each question should be in its own class
- Include appropriate JUnit test cases
- Add comments explaining the solution approach
- Include time and space complexity analysis where applicable
